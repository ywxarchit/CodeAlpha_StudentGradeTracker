# 🎓 CodeAlpha Student Grade Tracker

> A simple and efficient **Java console application** developed as part of the **CodeAlpha Java Programming Internship**.

The **Student Grade Tracker** is designed to manage student records and grades efficiently. It allows users to add student information, store grades, calculate performance statistics, and generate a structured summary of student performance.

---

## ✨ Features

* 👤 Add and manage student information
* 📚 Store multiple student records using `ArrayList`
* 📝 Enter and manage student grades
* 📊 Calculate average grades
* 🏆 Find the highest grade
* 📉 Find the lowest grade
* 📋 Generate a structured grade summary
* ⌨️ Interactive console-based interface
* 🧩 Demonstrates Object-Oriented Programming concepts
