# CodeAlpha Student Grade Tracker

A console-based Java application developed as part of the CodeAlpha Java Programming Internship.

## Project Overview

The Student Grade Tracker is designed to manage student information and grades efficiently. It allows users to add student records, calculate grade statistics, and display a structured summary of student performance.

## Features

- Add student information
- Store student records using ArrayList
- Enter and manage student grades
- Calculate average grades
- Identify highest and lowest grades
- Generate a structured grade summary
- Console-based user interaction
- Object-Oriented Programming concepts

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Collections Framework
- Scanner for user input
